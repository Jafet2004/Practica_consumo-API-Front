# Mi Página de Presentación 👋

## 📌 Descripción del proyecto

Este proyecto consiste en la creación de una página web personal utilizando HTML y CSS, como parte de una práctica de introducción al desarrollo frontend.

La página presenta información personal, mis intereses y mis redes sociales, aplicando la estructura básica de HTML y organizando los elementos principales de una página web.

## 🎯 Objetivos

- Identificar y utilizar la estructura básica de un documento HTML.
- Implementar etiquetas HTML para organizar el contenido.
- Crear una página web sencilla de presentación personal.
- Incorporar enlaces a redes sociales.
- Aplicar estilos CSS para mejorar la apariencia visual de la página.

## 🛠️ Tecnologías utilizadas

- **HTML5:** para estructurar el contenido de la página.
- **CSS3:** para personalizar el diseño y la apariencia visual.

## 📄 Contenido de la página

La página está organizada en las siguientes secciones:

Incluye un saludo y una breve descripción sobre mi interés por la tecnología, el desarrollo web y el aprendizaje de nuevas herramientas.

## 📁 Estructura del proyecto

```text
mi-pagina-presentacion/
├── index.html
├── estilo.css
└── README.md
```

- `index.html`: contiene la estructura y el contenido de la página.
- `estilo.css`: contiene los estilos visuales.
- `README.md`: describe el proyecto y sus características.

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en tu navegador web favorito.
4. Visualiza la página de presentación personal.

También puedes abrir el proyecto utilizando la extensión **Live Server** de Visual Studio Code.

## 📚 Aprendizajes obtenidos

Con esta práctica reforcé mis conocimientos sobre la estructura básica de HTML, el uso de encabezados, párrafos, listas y enlaces, así como la organización del contenido de una página web.

Además, comprendí la importancia de separar la estructura HTML de los estilos CSS para facilitar el mantenimiento y la presentación del sitio.
